Connect your Strava account to explore your activities
From strava.com/settings/api → My API Application
The token shown in the Strava UI only has read scope — it won't work here. You need to authorize manually to get activity:read_all scope:

Step 1 — paste this URL in your browser (replace YOUR_CLIENT_ID):
https://www.strava.com/oauth/authorize?client_id=YOUR_CLIENT_ID&redirect_uri=http://localhost&response_type=code&scope=activity:read_all

Step 2 — authorize the app. The browser redirects to localhost (which won't load — that's fine). Copy the code=… value from the URL bar.

Step 3 — exchange the code for tokens (run in terminal):
curl -X POST https://www.strava.com/oauth/token \
  -d client_id=YOUR_CLIENT_ID \
  -d client_secret=YOUR_CLIENT_SECRET \
  -d code=YOUR_CODE \
  -d grant_type=authorization_code

Copy the refresh_token from the response and paste it above.
